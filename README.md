# 🎨 DashArt – Frontend Flutter

**DashArt** est une application Flutter interactive permettant de découvrir, visualiser et analyser les œuvres d'art de deux musées : **le Musée du Louvre** et **le Musée Guimet**.  
Ce projet communique avec un **backend Node.js** pour charger les données en temps réel et suivre les interactions des utilisateurs.

---

## 🧩 Fonctionnalités clés

- 🖼️ Affichage d'œuvres d’art (images, titres, types)
- 🔄 Requête HTTP dynamique vers une API Node.js
- 🖱️ Sauvegarde des clics utilisateurs
- 📚 Catégorisation par type d’œuvre :
  - Peinture
  - Sculpture
- 📊 Pages dédiées :
  - Dashboards de données
  - Visualisations statistiques
  - Œuvres triées par musée

---

## 🚀 Stack technique

| Technologie     | Usage                                |
|----------------|----------------------------------------|
| Flutter (Dart) | Développement mobile et web           |
| `http`         | Appels API REST vers le backend       |
| `json`         | Parsing des données récupérées        |
| FlutterFlow    | Générateur de structure de projet UI  |
